Architecture: Static Snapshot vs Real-time API

Why Static Snapshot Outperforms Real-Time APIs

Instead of issuing hundreds or thousands of live HTTP queries to federal REST APIs every time a user pans or queries the map, this system adopts a Preprocessed Static Snapshot + Pure Frontend Rendering architecture.

✗ Real-Time API Weaknesses
  • Severe rate limits & bottlenecks: USGS Elevation Point Query API takes 200-500ms per point. Scanning a grid triggers tens of thousands of requests, crashing the browser or hitting IP blocks.
  • High network latency: ArcGIS REST vector queries for complex county polygons have heavy payload overhead and variable response delays.
  • Fragile uptime: Dependent on federal GIS server availability.
✓ Static Snapshot Advantages
  • Ultra-low data update frequency: FEMA 100-year flood maps and USGS LiDAR datasets are revised only once every several years or decades.
  • Instant 0-latency queries: All grid math is precalculated. The entire Santa Clara County South Bay model compiles to < 5 MB total binary data.
  • Zero hosting cost: Hostable on any free static provider (Cloudflare Pages, GitHub Pages, Amazon S3).

Mathematical Model & Raster Algebra

The predicted flood water depth is computed via cell-by-cell raster subtraction:

Water Depth = R_BFE - R_DEM

Where:

  • R_DEM: Ground elevation derived from 1-meter USGS 3D Elevation Program (3DEP) Bare-Earth airborne LiDAR (NAVD88 feet).
  • R_BFE: Water surface elevation surface generated by interpolating FEMA National Flood Hazard Layer (NFHL) Base Flood Elevation lines and static Zone AE/AH ponding elevations.

Risk Classification Tiers

  • ≤ 0 ft: Ground above flood water level (Dry land / Low risk)
  • 0 ~ 1 ft: Shallow flooding risk (Sheet flow & ponding)
  • 1 ~ 3 ft: Moderate flooding risk (Crawspace / ground floor danger)
  • > 3 ft: Deep water high risk (Velocity hazard, structural danger)

Technical Implementation Details

The frontend decodes flood depth, BFE, and ground elevation directly from an offscreen 4-channel Canvas lookup raster (flood_lookup_data.png) in < 0.1 milliseconds per click, delivering 60 FPS hardware-accelerated responsiveness.
